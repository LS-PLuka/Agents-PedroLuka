# Java profile

Apply the canonical standards with Java conventions. Prefer constructor injection and explicit dependencies. Use records for immutable boundary data when suitable, relevant Bean Validation, BigDecimal for money, UUID for identifiers, focused adapters, and centralized error translation. Use JUnit 5 with PT-BR descriptions and Testcontainers only for material dependencies. Control time through Clock when relevant. Do not impose Spring, Lombok, microservices, messaging, package layers, or a database without project evidence.
