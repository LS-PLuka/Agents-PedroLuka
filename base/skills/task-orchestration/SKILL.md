# task-orchestration

Derive objective and observable acceptance criteria. Select only roles with a concrete contribution. Sequence dependencies; isolate independent writers by ordinary directories. Include base hashes, write scope, context, limits, and prerequisite evidence. Stop when criteria are met.

Apply the canonical no-Git policy and language policy. Return evidence, performed checks, unperformed checks with reasons, and blockers. Do not expand authorization or claim execution that did not occur.
