# api-contracts

Define or review API and event contracts. Check producers, consumers, serialization, validation, status, errors, pagination, and compatibility. Preserve required external fields. Mocks do not prove interoperability.

Apply the canonical no-Git and language policies. Return evidence, performed checks, unperformed checks with reasons, and blockers.
