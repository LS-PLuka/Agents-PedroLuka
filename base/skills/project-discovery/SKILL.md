# project-discovery

Read scoped instruction files, manifests, representative production code and tests. Record detected profiles, commands, contracts, unknowns, and conflicts. Do not run Git. Avoid treating a filename alone as semantic ownership.

Apply the canonical no-Git policy and language policy. Return evidence, performed checks, unperformed checks with reasons, and blockers. Do not expand authorization or claim execution that did not occur.
